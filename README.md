# PaperCut

Cut through the fine print. PaperCut turns dense official documents into clear, trackable next steps.

**Design:** A Quantum Cupcake Creation ✦

The web client is published from `docs/` through GitHub Pages. GitHub Pages only serves static files; live registration, sign-in, persistent storage, and document processing require the separate Node.js backend to be deployed to an HTTPS service with persistent SQLite storage.

Development source and full-stack deployment package: `PaperCut_Standalone_FullStack.zip` (provided with the project).
